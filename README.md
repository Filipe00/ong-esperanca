# ONG Esperança

## Apresentação do Projeto

Projeto web desenvolvido para a ONG Esperança, com o objetivo de apresentar a organização e disponibilizar suas informações através de uma aplicação web.

## Tecnologias Utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização, responsividade e acessibilidade.
- **JavaScript** — implementação da lógica e funcionalidades da aplicação.
- **Vite** — ferramenta utilizada para build e otimização da versão de produção.

## Estrutura do Projeto

- `index.html` — página principal da aplicação.
- `css/` — arquivos de estilos CSS.
- `js/` — arquivos JavaScript e templates.
- `img/` — imagens utilizadas no projeto.
- `dist/` — versão gerada para produção pelo Vite.
- `vite.config.mjs` — configuração do processo de build.
- `.gitignore` — arquivos e pastas que não devem ser versionados.
